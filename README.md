# 衬衫衣橱

本地运行的电子衣橱：存你的衬衫、裤子、鞋子、配饰，选一身，用你自己的照片生成试穿效果。
换装走 fal.ai 的 API，一个 key 同时用两类模型：

- 整套换装和配饰：`fal-ai/nano-banana-pro/edit`（多图参考的编辑模型）
- 加强衬衫细节（可选）：`fal-ai/kling/v1-5/kolors-virtual-try-on`（专用试穿模型）

## 启动

需要 Python 3.10 或更高版本。

```bash
pip install -r requirements.txt
python app.py
```

浏览器会自动打开 http://127.0.0.1:8000 。这时是演示模式：流程都能点，但只会把单品贴在照片上示意，不花钱。

## 接上真实换装

1. 在 https://fal.ai/dashboard/keys 创建一个 key，并给账户充值。
2. 把 `.env.example` 复制一份改名为 `.env`，填上 `FAL_KEY=你的key`。
3. 重启 `python app.py`，右上角显示“已连接 fal.ai”即可。

## 费用

一身搭配最多调用三次模型：换衣服一次（衬衫、裤子、鞋子一起），配饰一次，“加强衬衫细节”一次。
按 fal.ai 写这份文档时的标价，编辑模型约 $0.15/张，试穿模型约 $0.07/张，所以一身大约 $0.15 到 $0.37。
界面上的估价来自 `.env` 里的 `EDIT_PRICE` / `VTON_PRICE`，实际以 fal.ai 账单为准。
同一张照片加同一身搭配只生成一次，之后从“穿过的搭配”里调回来不再收费。

## 照片怎么拍

- 你的照片：正面站立、全身入镜（脚要拍到）、光线均匀、只有你一个人。穿贴身、长度接近衬衫的衣服。
- 衬衫、裤子：白底平铺或挂拍，一张图一件，拍全。
- 鞋子：白底，斜侧拍一双。
- 配饰：一张图一件，并在名字里写清楚是什么（手表、领带、皮带），模型靠名字决定戴在哪。

## 换模型

在 `.env` 里改 `EDIT_MODEL` 或 `VTON_MODEL` 即可，例如把编辑模型换成便宜一些的 `fal-ai/nano-banana-2/edit`。
换成参数不同的其他模型时，需要改 `app.py` 里 `fal_edit` / `run_job` 的请求字段。

## 已知限制

- 结果是视觉预览，不代表真实的合身度和尺码。
- 细条纹、小格纹、文字 logo 最容易走样；走样时打开“加强衬衫细节”，或点“重新生成”。
- 编辑模型偶尔会改动肤色、身材比例或背景。用“按住看原照”对比。
- 照片会上传到 fal.ai 处理。衣橱图片和试穿结果只存在本机的 `data/` 文件夹，备份或搬家拷走这个文件夹即可。
