# 衬衫衣橱 e·closet

本地运行的电子衣橱：存你的衬衫、裤子、鞋子、配饰，选一身，用你自己的照片生成试穿效果。
换装走云端模型：默认只用**即梦（火山方舟 Seedream）**一个模型一次出图；也可以接阿里云百炼、可灵、fal.ai 做对比。模型接入都在 `providers.py`。

## 怎么用

- **衣杆**：衬衫、裤子挂在上面轻轻晃。鼠标划过一件，它会飞到画面中间、比在你身前；点一下穿上，再点一下脱下。最右边的 “+” 挂新衣服。
- **鞋架**：鞋子和配饰放在下面的架子上，用法一样。
- **镜子**：中间是你。生成后会跟着鼠标轻轻侧身；点“转一圈”会生成 5 个角度（约 5 张图的费用），之后自动转动，也可以左右拖动。
- **我的照片**：右上角，放全身照、生成形象照、切换用哪张。
- 上传的单品会自动去掉白底，只用于界面展示；交给模型的仍是原图。

## 启动

需要 Python 3.10 或更高版本。

```bash
pip install -r requirements.txt
python app.py
```

浏览器会自动打开 http://127.0.0.1:8000 。没填 key 时是演示模式：流程都能点，但只会把单品贴在照片上示意，不花钱。

## 接上真实换装

把 `.env.example` 复制一份改名为 `.env`，填 key 后重启：

| 平台 | 填什么 | 在哪开通 |
|---|---|---|
| **即梦（只填这个就能用）** | `ARK_API_KEY` | 火山引擎控制台 → 火山方舟 → API Key 管理创建 key；开通管理里开通 Doubao-Seedream-4.5 |
| 阿里云百炼 | `DASHSCOPE_API_KEY` | 百炼控制台创建 API Key，开通「AI试衣-Plus」「AI试衣-图片精修」「通义千问图像编辑」 |
| 可灵 | `KLING_ACCESS_KEY` `KLING_SECRET_KEY` | 可灵开放平台创建密钥，购买「虚拟试穿」资源包 |
| fal.ai（可选） | `FAL_KEY` | 原方案，留作对照 |

右上角会显示当前用哪家换装、哪家编辑。

## 换装流程

在 `.env` 里用 `PIPELINE=seedream / bailian / kling / fal` 切换，默认用第一个填了 key 的。

| 流程 | 衬衫和裤子 | 鞋、穿法、配饰 |
|---|---|---|
| `seedream` | 即梦一次调用：照片 + 衬衫 + 裤子 + 鞋 + 配饰（最多 14 张参考图），穿法写在指令里 | 同一次调用 |
| `bailian` | 百炼 aitryon-plus 一次换上下装（可选再精修一轮） | 通义千问图像编辑：换鞋、按选择调塞进/放外面、袖子、领口；配饰每次最多 2 件 |
| `kling` | 可灵试穿分两次换；塞进 = 先衬衫后裤子，放外面 = 先裤子后衬衫 | 同上（需要百炼 key） |
| `fal` | Nano Banana Pro 一次换全身（原方案） | 同一个模型 |

## 自动检查效果

用即梦时，每张图生成后会在后台用豆包视觉模型（同一个 `ARK_API_KEY`）对照原照和单品图检查五项：像本人、衬衫还原、整身完整、画面自然、穿法正确。
有一项不合格就自动重新生成一次，留下更好的那张。界面上不显示这个过程，只多一个“检查效果”的进度。
检查结果记在 `data/db.json` 每条搭配的 `check` 字段里，方便以后统计。

- 关掉：`.env` 里写 `AUTO_CHECK=0`
- 最多生成几次：`AUTO_RETRY=2`（每多一次多一份生成费用）
- 检查用的模型：`CHECK_MODEL`，默认 `doubao-seed-1-6-250615`，需要在火山方舟开通；检查失败不影响出图

## 费用

界面上显示的是估价（人民币），来自 `.env` 里的 `PRICE_*`，实际以控制台账单为准。
aitryon-plus 官方标价 0.5 元/张；精修、通义图像编辑、可灵试穿的默认值是估计，请按控制台价格改。
同一张照片加同一身搭配只生成一次，之后从“穿过的搭配”里调回来不再收费。

## 人物形象（底片）

试穿是在你自己的照片上换衣服，底片决定一半效果。两种方式：

1. **直接用照片**：按下面的拍法拍一张，上传到「照片」。
2. **生成形象照**：在「照片」里点某张照片下面的“生成形象照”，用图像编辑模型整理成标准底片：同一个人，正面站姿、手臂稍离身体、长发在肩后、白色贴身短袖加浅灰修身长裤、浅灰影棚背景。原照保留，新图名为“形象照”。随手拍的照片背景乱、穿着裙子或外套时用这个。生成后先用“按住看原照”核对像不像你，不像就删掉重新生成，或者直接用原照。

性别在 `.env` 里用 `GENDER=woman / man` 设置，默认 woman。

## 照片怎么拍

- 你的照片：正面站立、全身入镜（头到脚）、光线均匀、只有你一个人。穿贴身短袖上衣和修身长裤，不要穿裙子、连衣裙或宽松外套；长发拨到肩后，露出脖子和肩膀（衬衫领子要换到这里）；手臂自然垂下，别挡住腰（塞衣角要换到这里）。
- 衬衫、裤子：白底平铺或挂拍，一张图一件，拍全，衬衫扣好扣子。
- 鞋子：白底，斜侧拍一双。
- 配饰：一张图一件，并在名字里写清楚是什么（项链、耳环、手表、腰带、包），模型靠名字决定戴在哪。

## 换模型

模型名都在 `.env` 里改（见 `.env.example`）。要接新的一家，在 `providers.py` 里加一组函数，再在 `app.py` 的 `build_plan` 里加一条流程。

## 已知限制

- 结果是视觉预览，不代表真实的合身度和尺码。
- 细条纹、小格纹、文字 logo 最容易走样；走样时打开“精修衣服细节”，或点“重新生成”。
- 百炼试衣只给衬衫不给裤子时，裤子可能由模型自行生成；建议衬衫和裤子都选。
- 编辑模型偶尔会改动肤色、身材比例或背景。用“按住看原照”对比。
- 照片会上传到所选平台处理（百炼的临时存储 48 小时后自动删除）。衣橱图片和试穿结果只存在本机的 `data/` 文件夹，备份或搬家拷走这个文件夹即可。
