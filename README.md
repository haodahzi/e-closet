# 衬衫衣橱 D-Closet · 定制销售版

本地运行的电子衣橱：存你的衬衫、裤子、鞋子、配饰，选一身，用你自己的照片生成试穿效果。
换装走云端模型：默认只用**即梦（火山方舟 Seedream）**一个模型一次出图；也可以接阿里云百炼、可灵、fal.ai 做对比。模型接入都在 `providers.py`。

## 客户档案（西装、衬衫、工服定制的售前用法）

顶部“客户档案库”（或点“客户：xxx”）打开**客户档案库**：一个独立页面，所有客户以卡片排开（照片、阶段、联系方式、搭配数、跟进日期），可以搜索、按阶段筛选、导出表格；每张卡片“去试穿”直接回到试穿界面，“档案”在右侧打开这位客户的详情。一位客户一份档案，基本信息、量体数据、**照片和形象照**、跟进记录、试穿搭配都在这里（原来的“形象”就是客户；原来单独的“客户照片”入口已并进来）。

- **建档**：“+ 新客户”，填姓名、类型、性别，自动配一个默认模特；在档案的“照片与形象照”里“+ 添加照片”放客户本人的全身照，点照片下面的“生成形象照”整理成标准底片，点哪张就用哪张试穿。
- **档案内容**：电话、微信、公司、跟进阶段（线索 → 已量体 → 方案中 → 已报价 → 已成交 / 已流失）、下次跟进日期、预算、工服人数、场合，面料颜色版型偏好，量体数据（身高、体重、领围、肩宽、胸围、腰围、臀围、袖长、衣长、裤长）和量体日期，备注。
- **跟进记录**：打了电话、约了量体、发了方案，一条一条记，带时间。
- **列表**：按阶段筛选、搜索姓名电话公司；该跟进的客户（跟进日期已到）排最前面并标红。
- **性别**：档案里填了，生成形象照时按客户的来；没填才用设置里的默认性别。
- **导出表格**：客户列表右上角“导出表格”，下载 CSV，Excel 直接打开。
- 老数据不用动：以前的“形象”自动成了客户，第一次编辑时补全资料。

## 设置面板

右上角“⚙ 设置”：即梦 / 百炼 / 可灵 / fal 的 API Key、模型名、接口地址，换装流程，自动检查，转身视频参数，估价，抠图模型，以及各个本地文件的位置，都在这里改，保存后**马上生效，不用重启**。

- 优先级：设置面板里保存的值 > `.env` > 默认值。面板里点“恢复默认 / 清除”就回到 `.env` 的值。`.env` 继续可用，但不再是必须的。
- API Key 保存在 `data/closet.db`，页面上只显示末四位，不会把明文发回浏览器；浏览器也无法直接下载这个文件。**不要把 data 文件夹发给别人。**

## 试穿界面（尽量简洁）

主界面只做一件事：给当前客户挑衣服、看效果。衣杆和鞋架挑衣服（点一下穿上，再点一下脱下）；“今天这一身”只列出已穿上的几件；“穿法与姿势”默认收起，一行字显示当前设置，点开才调；镜子上常用的只有“按住看原照 / 转一圈 / 重新生成”，“修一下、重转一次、撤销修改”收在“更多”里。客户、衣服、设置都在各自的页面里管理：客户档案库、服装库、设置。

## 怎么用（衣橱）

- **品类和性别**：衣橱有衬衫、POLO衫、西装外套、裤子、腰带、鞋子、帽子、配饰。POLO衫和衬衫占同一个“上衣”位（二选一），西装外套单独一个位，可以穿在衬衫或 POLO 衫外面，下面有“外套敞开 / 外套扣上”；POLO 是短袖，所以不显示“卷袖”。在服装库上传时要选**男款 / 女款 / 通用**（默认跟着当前客户的性别，之后记住上次的选择）；衣杆左上角可以按“全部 / 男款 / 女款”筛选，切换客户时自动跟着客户的性别走。通用款和以前上传的老单品两边都显示。性别也会写进给模型的指令里（比如 men's suit jacket），服装库里点“改名 / 款式”可以改。百炼、可灵流程里西装外套在最后一步用图像编辑模型穿上。
- **衣杆**：衬衫、裤子用木衣架侧挂在镀铬衣杆上，衣服盖住衣架、只露出挂钩。鼠标划过一件，它转成正面、变大，两边的衣服被挤开并跟着摆动；点一下穿上，再点一下脱下。衣服挂得多会互相挤，但不会滑出衣杆两端。衣橱页面只负责挑衣服，不能在这里上传或整理——都在“服装库”里。
- **腰带**：放在下面的架子上（卷起来的样子）。选上腰带会自动改成“塞进裤子”，腰带才露得出来。
- **鞋架**：鞋子、帽子和其他配饰放在衣杆下面的架子上。
- **一致性**：每件单品上传后会自动写一句文字描述（颜色、材质、鞋带、扣子等），生成时图文一起交给即梦；生成后自动检查衬衫、裤子、鞋子、腰带、帽子、配饰、长相、穿法、白底，哪一项不对只修那一项，只有画面整体有问题才整身重做。
- **修一下**：你自己发现哪里不对，点人像右上角“修一下”，勾选不对的部分、写一句说明，只修这些；修坏了点“撤销修改”回到上一版。
- **白底**：试穿图、形象照、转身视频都要求纯白背景。生成后会把偏灰的背景统一刷成纯白，但先用本地抠图模型把人圈出来，人身上一个像素都不动；搭配里有白色、米白单品时，按“头顶到鞋子”的整个人形保护，白裤子、白衬衫不会被当成背景刷掉（没装抠图模型时遇到白色单品就不刷）。洗白前的原图保留在 `data/results/*_raw.jpg`。
- **白色单品**：程序会自动认出白色、米白、象牙白的单品，给即梦的指令里额外要求和白背景分开、褶皱有自然阴影、不过曝；自动检查也会看白色单品的轮廓清不清楚，不清楚就自动修一次。
- **客户（形象）**：衣橱是共用的，照片按客户分开。一张原照和由它生成的形象照算同一个形象；同一个人的其他照片可以在「我的照片」里用“归到…”放进同一个形象，也能单独成一个新形象，形象可以改名（比如“我”“妈妈”）。顶部“客户：xxx”可以切换：点哪位客户，镜子和 Looks 就只显示这个形象的照片和过往搭配，切回来会回到上次看的那一套。照片删了，它生成过的搭配仍然归在原来的形象下。
- **今天这一身**：选好的单品、穿法（塞进/放外面、袖子、领口）、姿势和“生成试穿”按钮。
- **姿势**：双手自然下垂（默认）/ 双手微张 / 单手插兜，写进给即梦的指令里，不再让模型随手换姿势，几套搭配放在一起更统一。要做“转一圈”视频推荐“双手微张”：手臂和身体分开，转身最稳；“单手插兜”转身时手容易乱动。换一个姿势算一次新的生成。
- **镜子**：右边是你。生成后会跟着鼠标轻轻侧身。点“转一圈”会用即梦视频模型 Seedance 做一段“360° 转台展示”视频：站在看不见的旋转台上，以身体中轴为轴心整体匀速旋转；像静止的雕塑，手臂、腿、脚、头、表情都不动，不迈步、不摆手、不扭腰；身体比例和五官不变形；最后回到正面停住，相机固定（默认只把试穿图当首帧：Seedance 2.0 不允许用真人照片同时做首帧和尾帧。换成支持首尾帧的模型时，`.env` 里 `TURN_LAST_FRAME=1` 会先试首尾帧）。不满意可以点“重转一次”重新生成。`.env` 里 `TURN_MODE=orbit` 可以改成“人不动、镜头环绕”。做好以后再点“转一圈”重播，也可以左右拖动看转身，松手会转回正面。播放时页面会自动找到“转回正面”的那一刻并停在那里，视频最后几帧如果人有小动作也不会播出来；发给视频模型的照片会先补白边成标准比例。播放前页面会量出视频第一帧里人的头顶、脚底和中心线，把视频缩放、移动到和照片里的人完全重合（视频模型自己加的黑边会剪掉），从照片原地开始转，转回来淡回照片，人的大小位置不跳。视频要在火山方舟开通任意一个 Seedance 模型（比如 Seedance 1.0 pro fast），每段约 ¥1–2（估计）。
- **色卡**：每套搭配会从各件单品的抠图里提取 3–5 个主色，浮在照片左侧竖排成色卡（不挤占人像位置；HEX 色值 + 中英文色名，仿色卡样式，不是 Pantone 官方色号）。本地计算，不花钱。
- **我的照片**：右上角，放全身照、生成形象照、切换用哪张。
- **抠图**：上传的单品会用本地抠图模型（rembg）自动去背景，只用于衣杆上的展示。模特穿着拍的衬衫、裤子会再用衣服分割模型去掉头和手（边缘可能不够干净）。第一次运行会下载抠图模型（每个约 170MB）。
- **衣架效果**：整理过的衬衫、裤子会由即梦生成“挂在木衣架上”的样子，衣杆上直接用它自带的衣架挂起来，最真实。自己挂在衣架上、白墙前完整拍下的照片也会被认出来直接挂。
- **服装库**：顶部“服装库”进入。上传（一次可选好几张）、改名、改男款/女款、删除、拖动排序都在这里；按品类和性别筛选。**整理单品图**也在这里：上传时勾选“先整理成干净的单品图”，或对已入库的衣服点“整理成单品图”，用即梦把衣服单独整理成白底商品图（原图保留，可以“还原原图”），衣杆上更好看，换装也更准。选中某个品类后，按住卡片左右拖动就能排顺序，衣杆上按这个顺序挂。
- **默认模特**：服装库的“模特”里内置了男、女两个默认模特（中性白色人台，没有脸，占位级素材）。新建客户时按性别自动配一个，不用等拍照就能试穿方案；客户详情里“+ 模特”可以换，“+ 照片”放客户本人的照片。想要写实模特：到“服装库 → 模特”上传你有授权的模特全身照（正面站立、白底最好），之后建档就能选它。内置的两张用 `python tools/make_models.py` 生成。

## 作为桌面应用打开

**打包好的版本**（Windows 的 `D-Closet.exe`、macOS 的 `D-Closet.app`）：双击就是一个独立窗口，不用开终端、不用开浏览器，数据放在系统的应用数据目录（Windows `%APPDATA%\D-Closet`、macOS `~/Library/Application Support/D-Closet`）。打包有两种办法：

- GitHub 上手动运行 “Build desktop app” 工作流（Actions 页面 → Run workflow），在 Windows 和 macOS 上各打一份，下载 artifact 即可；
- 或者在对应系统上自己跑：`pip install -r requirements-desktop.txt` 然后 `python build_app.py`，输出在 `dist/`。

**不打包，直接双击启动**：Windows 双击 `启动衣橱.bat`，macOS 双击 `启动衣橱.command`（Linux 运行 `启动衣橱.sh`）。第一次会自动装依赖（几分钟，只做一次），之后秒开，同样是独立窗口。需要先装 Python 3.10 或更高版本。没装 `pywebview` 或系统缺少 WebView 组件时，会退回用默认浏览器打开。

## 启动（命令行）

需要 Python 3.10 或更高版本。

```bash
pip install -r requirements.txt
python app.py          # 浏览器打开
python desktop.py      # 原生窗口打开（pip install pywebview）
```

浏览器会自动打开 http://127.0.0.1:8000 。没填 key 时是演示模式：流程都能点，但只会把单品贴在照片上示意，不花钱。

## 接上真实换装

最省事：打开页面右上角“⚙ 设置”，把 key 粘进去保存。也可以把 `.env.example` 复制一份改名为 `.env`，填 key 后重启：

| 平台 | 填什么 | 在哪开通 |
|---|---|---|
| **即梦（只填这个就能用）** | `ARK_API_KEY` | 火山引擎控制台 → 火山方舟 → API Key 管理创建 key；开通管理里开通 Doubao-Seedream-4.5 |
| 阿里云百炼 | `DASHSCOPE_API_KEY` | 百炼控制台创建 API Key，开通「AI试衣-Plus」「AI试衣-图片精修」「通义千问图像编辑」 |
| 可灵 | `KLING_ACCESS_KEY` `KLING_SECRET_KEY` | 可灵开放平台创建密钥，购买「虚拟试穿」资源包 |
| fal.ai（可选） | `FAL_KEY` | 原方案，留作对照 |

右上角会显示当前用哪家换装、哪家编辑。

## 换装流程

在 `.env` 里用 `PIPELINE=seedream / bailian / kling / fal` 切换，默认用第一个填了 key 的。

| 流程 | 衬衫和裤子 | 鞋、穿法、配饰 |
|---|---|---|
| `seedream` | 即梦一次调用：照片 + 衬衫 + 裤子 + 鞋 + 配饰（最多 14 张参考图），穿法写在指令里 | 同一次调用 |
| `bailian` | 百炼 aitryon-plus 一次换上下装（可选再精修一轮） | 通义千问图像编辑：换鞋、按选择调塞进/放外面、袖子、领口；配饰每次最多 2 件 |
| `kling` | 可灵试穿分两次换；塞进 = 先衬衫后裤子，放外面 = 先裤子后衬衫 | 同上（需要百炼 key） |
| `fal` | Nano Banana Pro 一次换全身（原方案） | 同一个模型 |

## 出问题了先跑诊断

```bash
python check.py            # 免费：测网络、key、模型开通
python check.py --image    # 再真的生成一张测试图（约 ¥0.2）
```
出错的详细原因也会打印在运行 `python app.py` 的终端里，并记在 `data/errors.log`。

## 自动检查效果

用即梦时，每张图生成后会在后台用豆包视觉模型（同一个 `ARK_API_KEY`）对照原照和单品图检查五项：像本人、衬衫还原、整身完整、画面自然、穿法正确。
有一项不合格就自动重新生成一次，留下更好的那张。界面上不显示这个过程，只多一个“检查效果”的进度。
检查结果记在数据库里每条搭配的 `check` 字段里，方便以后统计。

- 关掉、最多生成几次（每多一次多一份生成费用）、检查用的模型（默认 `doubao-seed-1-6-250615`，需要在火山方舟开通），都在“设置”里改；检查失败不影响出图

## 费用

界面上显示的是估价（人民币），来自“设置 → 估价”（或 `.env` 里的 `PRICE_*`），实际以控制台账单为准。
aitryon-plus 官方标价 0.5 元/张；精修、通义图像编辑、可灵试穿的默认值是估计，请按控制台价格改。
同一张照片加同一身搭配只生成一次，之后从“穿过的搭配”里调回来不再收费。

## 人物形象（底片）

试穿是在你自己的照片上换衣服，底片决定一半效果。两种方式：

1. **直接用照片**：按下面的拍法拍一张，在客户档案里“+ 照片”上传。
2. **生成形象照**：在「照片」里点某张照片下面的“生成形象照”，用图像编辑模型整理成标准底片：同一个人，正面站姿、手臂稍离身体、长发在肩后、白色贴身短袖加浅灰修身长裤、纯白影棚背景。原照保留，新图名为“形象照”。随手拍的照片背景乱、穿着裙子或外套时用这个。生成后先用“按住看原照”核对像不像你，不像就删掉重新生成，或者直接用原照。

性别优先用客户档案里填的；没填就用“设置 → 换装流程 → 默认性别”（默认男）。

## 照片怎么拍

- 你的照片：正面站立、全身入镜（头到脚）、光线均匀、只有你一个人。穿贴身短袖上衣和修身长裤，不要穿裙子、连衣裙或宽松外套；长发拨到肩后，露出脖子和肩膀（衬衫领子要换到这里）；手臂自然垂下，别挡住腰（塞衣角要换到这里）。
- 衬衫、裤子：白底平铺或挂拍，一张图一件，拍全，衬衫扣好扣子。
- 鞋子：白底，斜侧拍一双。
- 配饰：一张图一件，并在名字里写清楚是什么（项链、耳环、手表、腰带、包），模型靠名字决定戴在哪。

## 换模型

模型名都在“设置”里改（也可以写在 `.env`，见 `.env.example`）。要接新的一家，在 `providers.py` 里加一组函数，再在 `app.py` 的 `build_plan` 里加一条流程。

## 已知限制

- 结果是视觉预览，不代表真实的合身度和尺码。
- 细条纹、小格纹、文字 logo 最容易走样；走样时打开“精修衣服细节”，或点“重新生成”。
- 百炼试衣只给衬衫不给裤子时，裤子可能由模型自行生成；建议衬衫和裤子都选。
- 编辑模型偶尔会改动肤色、身材比例或背景。用“按住看原照”对比。
- 照片会上传到所选平台处理（百炼的临时存储 48 小时后自动删除）。衣橱、客户档案、设置都存在本机的 `data/` 文件夹：数据库是 `data/closet.db`（SQLite），图片在 `data/items/` 和 `data/results/`。备份或搬家：关掉程序，拷走整个 `data/`。
- 从旧版升级：第一次启动会自动把 `data/db.json` 导入 `closet.db`，原文件改名为 `db.json.migrated` 留作备份。
