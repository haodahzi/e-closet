# E-Closet 衬衫电子衣橱 · 产品与技术方案

> 目标：上传自己所有衬衫（及下装、鞋、配饰），自由搭配，并在「真人形象」上逼真试穿；衬衫支持塞进 / 放下（及半塞）；第一阶段静态图，最终支持固定动作下的 360° 旋转查看。产品调性：高级、时装杂志感。

---

## 1. 调研：可借鉴的仓库与最佳实践

### 1.1 电子衣橱类（产品形态参考）
| 项目 | 可学习点 |
|---|---|
| [lazztech/Libre-Closet](https://github.com/lazztech/Libre-Closet) | 自托管 PWA、客户端抠图、SQLite 本地存储、搭配管理，适合参考数据模型和上传流程 |
| [zebangeth/ai-closet](https://github.com/zebangeth/ai-closet) | AI 自动抠图 + 自动打标签（品类/颜色/季节）、自由画布拖拽搭配、上传个人照生成上身效果 |
| Google Doppl（产品，无 API） | 「个人数字分身 + 组合整套试穿 + 动态视频」的交互范式，是我们最接近的对标 |

### 1.2 图像虚拟试穿（VTON，静态阶段核心）
| 模型 | 特点 | 适用 |
|---|---|---|
| [IDM-VTON](https://github.com/yisol/IDM-VTON) | 衣物细节（印花、条纹、Logo）还原好，真实场景鲁棒 | 衬衫高保真主力 |
| CatVTON（Zheng-Chong） | 轻量、好部署，单图试穿 | 低成本/快速预览 |
| OOTDiffusion | 上装/下装/连衣裙，社区成熟 | 下装试穿 |
| OmniTry（NeurIPS 2025） | 免 mask，可试戴任意穿戴物：首饰、包、帽、眼镜 | **配饰** |
| Any2AnyTryon（ICCV 2025） | 文本指令控制试穿，免 mask/pose | 指令式控制（如 "tucked in"） |
| Wear-Any-Way（ECCV 2024, 阿里） | 点/拖拽控制穿法：**塞衣角、卷袖、敞开外套**，支持多件 | **塞进/放下/半塞** 的学术最佳参考 |

商业 API 备选：FASHN（试穿专用 API，入门约 $19/200 credits）、Gemini 图像模型（Nano Banana，多参考图 + 文字指令，适合"整套搭配一次出图"）。

> ⚠️ 许可证：IDM-VTON / CatVTON / OOTDiffusion 等学术模型多为**非商用许可（CC BY-NC-SA 类）**。自用没问题，商用前必须核实或改用商业 API。

### 1.3 视频 / 360° 试穿（终局阶段）
| 项目 | 说明 |
|---|---|
| [CatV2TON](https://github.com/Zheng-Chong/CatV2TON)（CVPR'25 Workshop） | 单个 DiT 同时支持图像和**视频**试穿，长视频分段推理保持时序一致 |
| [ViViD](https://github.com/alibaba-yuanjing-aigclab/ViViD) | 视频试穿，可对一段"人在原地转圈"的视频换衣 |
| Pippo（Meta, CVPR'25） | 单张照片生成 1K 分辨率**环绕视角**人像 |
| HumanOrbit（CVPR'26 Findings） | 单图生成 360° 环绕视频，保持身份与服装一致 |

### 1.4 结论（最佳实践）
1. **不要让一个生成模型包办一切**。拆成：衣物数字化（一次）→ 分身建模（一次）→ 试穿渲染（按搭配）→ 缓存。
2. **"塞进/放下"用叠穿顺序解决**：分层试穿时，*先上衣后下装* = 塞进（裤腰压住衣摆）；*先下装后上衣* = 放下（衣摆盖住裤腰）。半塞（French tuck）再用指令式/点控模型局部修。
3. **360° 不必真 3D**：固定动作 + 预采集转台序列 + 视频试穿 → 拖拽播放帧序列，即可得到"像 3D"的效果；真 3D 布料仿真（CLO/Style3D）需要版型数据，不适合用户自拍衬衫。
4. **时尚感 = 素材一致性**：所有单品统一抠图、统一光影/阴影/比例，比任何 UI 装饰都重要。

## 2. 产品设计

### 2.1 核心模块
1. **衣橱 Closet**：按品类 / 颜色 / 领型 / 面料 / 季节浏览；衬衫有专属属性：领型（标准、温莎、扣领、古巴领、立领）、袖长、版型（修身/常规/宽松）、**下摆形状（弧形摆/平摆）**、面料（牛津纺、府绸、亚麻、法兰绒…）、图案。
2. **搭配工作室 Studio**
   - *平铺模式 Flat-lay*：杂志拼贴风画布，即时、零成本，拖拽组合。
   - *上身模式 On Me*：在你的真人分身上渲染；切换「塞进 / 放下 / 半塞」「袖口卷起」。
   - *360 模式*（阶段三）：拖拽旋转查看固定站姿。
3. **Lookbook**：保存的搭配成刊，按场合（通勤 / 约会 / 度假）编排，可分享卡片。
4. **穿搭日历 & 数据**：记录每日穿着，统计单次穿着成本、闲置衬衫、颜色分布。
5. **AI 造型师**：根据天气、场合、已有单品推荐组合；规则 + LLM：弧形摆修身衬衫建议塞进，平摆短款（古巴领/夏威夷）建议放下。

### 2.2 视觉调性
- **编辑部风格**：大留白、米白/象牙底 + 炭黑文字，单一强调色（如酒红或深墨绿）。
- 字体：标题用 Didone 衬线（Bodoni Moda / Playfair Display），正文用几何无衬线（Inter / Neue Haas 类）。
- 单品图统一：纯色背景、柔和投影、统一比例与居中，像品牌官网。
- 动效：卡片翻页、衣架滑动、换装时的柔和溶解；360 视图像秀场转台。
- 分身照片风格：影棚灯光、中性背景，避免"AI 塑料感"。

## 3. 技术架构

```
[Web/PWA (Next.js + Tailwind) / 后续 Expo App]
        │  上传、搭配、查看
        ▼
[API 层 (Next.js Route / FastAPI)] ── [Postgres + 对象存储 (Supabase)]
        │  异步任务
        ▼
[任务队列] → [GPU 推理 (Modal / Replicate / fal.ai 或 商业 API)]
   ├─ 抠图: BiRefNet / rembg
   ├─ 打标签: 多模态 LLM（品类、颜色、领型、摆型…）
   ├─ 平铺规范化: 去皱/校正透视/统一阴影
   ├─ 试穿: IDM-VTON(上衣) / OOTDiffusion(下装) / OmniTry(配饰) 或 FASHN / Gemini
   ├─ 修复: 人脸贴回 + 超分(Real-ESRGAN)
   └─ 360: CatV2TON 视频试穿 / 环绕视角生成
```

### 3.1 关键流程
**A. 单品入库**：拍照（平铺或挂拍）→ 抠图 → 规范化 → LLM 自动打标签（用户可改）→ 生成缩略图与试穿用"服装图"。

**B. 分身建模（一次性）**：
- 拍摄指引：全身正面、侧面、背面，紧身/贴身基础衣（便于换装），自然站姿；可选面部特写。
- 生成"基础分身"：统一光线背景，锁定 2–3 个固定姿势（正面站姿、3/4 侧、背面）。
- 阶段三追加：原地转一圈的视频（或手机转台），抽 24–36 帧作为 360 底片。

**C. 整套试穿（分层渲染）**：
```
基础分身
  → 若"塞进"：上衣 → 下装 → 鞋 → 配饰
  → 若"放下"：下装 → 上衣 → 鞋 → 配饰
  → 若"半塞"：放下结果 + 指令/点控局部编辑前摆
  → 人脸/手部从原图贴回（保身份）→ 超分 → 缓存
```
缓存键：`hash(分身ID, 姿势, 单品ID列表, 穿法参数)`，同一搭配不重复付费。

**D. 质量控制**：衣物保真检查（颜色差、图案 SSIM）、身份相似度（人脸 embedding）、失败自动重试或换模型。

### 3.2 数据模型（简化）
- `items`：id, category(shirt/bottom/shoes/accessory), image_raw, image_clean, attrs(jsonb: collar, hem, fit, fabric, color…)
- `avatars`：id, poses[{pose, image}], turntable_frames[]
- `outfits`：id, item_ids[], styling(jsonb: tuck=in|out|half, sleeves=down|rolled)
- `renders`：outfit_id, avatar_id, pose, kind(static|turntable), urls[], status, cache_key
- `wear_logs`：outfit_id, date, weather

## 4. 分阶段路线

| 阶段 | 内容 | 关键技术 | 周期（1–2 人） |
|---|---|---|---|
| **P0 衣橱 MVP** | 上传、抠图、自动打标签、衣橱浏览、平铺搭配画布 | Next.js, Supabase, BiRefNet, 多模态 LLM | 3–4 周 |
| **P1 静态上身** | 分身建模、单张正面试穿、塞进/放下切换、缓存 | 先用商业 API 验证效果（FASHN / Gemini），再评估自托管 IDM-VTON/CatVTON | 4–6 周 |
| **P1.5 全身整套** | 鞋、配饰、半塞、卷袖；多姿势（正/侧/背） | OmniTry、Any2AnyTryon、分层渲染 | 4 周 |
| **P2 多角度** | 8 个固定角度静态图 → 拖拽切换（伪 360） | 每角度分身底片 + 逐角度试穿 + 一致性校验 | 3–4 周 |
| **P3 平滑 360** | 24–36 帧转台序列视频试穿，帧插值，手势旋转 | CatV2TON / ViViD；或正面试穿图 → 环绕视角生成（HumanOrbit/Pippo 思路）；RIFE 插帧 | 6–8 周（研究性） |
| P4（可选） | 3D Gaussian 分身、AR 镜子 | 研究级，视效果再定 | — |

**建议先验证的三件事（2 周内的技术 Spike）**：
1. 你的 10 件真实衬衫（含条纹、格子、Logo、亚麻）在你本人照片上的试穿保真度：商业 API vs 开源模型对比。
2. 分层顺序实现塞进/放下的成功率。
3. 用一段自己转圈的视频跑 CatV2TON，看 360 一致性是否可接受。

## 5. 风险与应对
| 风险 | 应对 |
|---|---|
| 生成"不像我"（身份漂移） | 人脸贴回、固定分身底片、身份相似度阈值 |
| 衣物细节失真（条纹扭曲、Logo 变形） | 高分辨率服装图、高保真模型、自动 QA + 重试 |
| 360 帧间闪烁 | 视频试穿模型 + 固定动作 + 插帧；先上 8 角度离散方案 |
| 成本 | 平铺模式免费即时；上身渲染异步 + 强缓存；只对保存的搭配生成 360 |
| 隐私（身体照片） | 加密存储、可一键删除、默认不公开，可选本地/私有部署 |
| 许可证 | 学术模型非商用；产品化时切商业 API 或获得授权 |

## 6. 推荐起步决策
- **平台**：Web PWA 先行（手机可添加到主屏），后续再做原生 App。
- **试穿引擎**：P1 用商业 API 快速验证体验，同时并行搭建开源管线；以抽象接口 `TryOnProvider` 隔离，便于替换。
- **差异化**：专注"衬衫"——领型/摆型/面料的专业标签、穿法控制（塞/放/半塞/卷袖）、编辑部级视觉，是通用试穿产品没做透的点。
